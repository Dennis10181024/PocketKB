# PocketKB 組員試玩

劇情、評分及研究資料流程為草稿，待人工審查。此版適合組員測試。

1. 在 Windows 安裝 [Node.js LTS](https://nodejs.org/)，下載或解壓專案後雙擊 `start-play.bat`，瀏覽器會開啟選擇題試玩頁。遇到瀏覽器沒開的情況，複製終端機裡的網址。退出服務時關閉終端機。
2. 先玩「宿舍火災」和「學校地震」。想玩捷運、淹水和颱風停電時，在情境清單展開「演練設定」，勾選「顯示草稿情境」。捷運有突發攻擊、人群恐慌與非血腥受傷描述，可跳過或隨時停止。
3. 玩完按「下載試玩紀錄」；想中途離開時，展開「停止演練」可選擇結束並下載。到瀏覽器的下載位置（Windows 通常是「下載」資料夾，iPhone 依 Safari 設定從「檔案」App 找「下載」），挑出本次的 `PocketKB-*.jsonl` 傳給組員。只傳這幾個檔案即可。未匯出就關頁，該場的網頁暫存會消失。
4. 如果用手機，讓手機和電腦在同一個 Wi-Fi，在電腦專案目錄執行 `start-play.bat --lan`，手機掃終端機 QR code。普通區網 HTTP 需要保持 Wi-Fi；iPhone 要加入主畫面後斷網重開，請看 [iPhone 試玩說明](docs/IOS_WEB_PLAY_REPORT.md)。

紀錄包含隨機場次 ID、情境包及評分器版本、進入／重來／退出、每題顯示順序、所選選項代碼、作答與背景時間、安全判定、實際觸發的事件及結局。這個入口不收姓名、IP、照片、自由文字或模型輸出。檔案只由玩家下載與自行分享。

盲測時先單獨發 [題本](docs/BLIND_OPTION_TEST.md) 給作答者。 [答案與計分](docs/BLIND_OPTION_TEST_KEY.md) 由主持人保留到收卷。
