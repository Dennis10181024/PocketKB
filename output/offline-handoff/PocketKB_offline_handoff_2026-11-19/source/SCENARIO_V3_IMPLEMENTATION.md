# PocketKB v3 因果情境核心

更新日期：2026-10-29

本文記錄 v3 核心初次接入 Android 的狀態。最新版本的線上教練、網頁展示及驗收範圍見 [2026-11-15 更新說明](RELEASE_NOTES_2026-11-15.md)。

## 本輪完成

Android 已接入共用 `ScenarioRuntimeV3`。介面維持 `create → step → review`，劇本只描述狀態、動作、前置條件、後果與終止結果；只有 runtime 可以改變情境或指定結局。

目前可玩的 v3 情境：

1. 地震－學校教室：可完成撤離，也可能因搖晃時奔向電梯而危急失敗。
2. 地震－受困住家：設定為沒有安全出口；完成條件是定位、保存電量與物資、穩定待救，不能顯示成已逃生或已獲救。
3. 淹水－低窪住宅：撤離窗口已關閉；進地下停車場或涉水離開會失敗，正確路徑為垂直避難並等待救援。
4. 土石流－山區道路：及早依官方警戒折返可完成撤離；硬闖封閉區或走溪谷捷徑會失敗。
5. 堰塞湖－下游聚落：立即依命令撤離可到達指定高地；拖延收拾會使撤離路線中斷，目標隨即改成就近垂直避難、定位與待救。

既有宿舍火災 v2 仍保留，尚未遷移至通用 v3 核心。

五個 v3 劇本現在都包含 3 個以上學習目標、3 個以上常見迷思、2 個以上反思問題與至少一項官方來源。Android 開始畫面會先顯示「這次要練習」，演練畫面會標示學習模式不計時。結束頁已改用結構化回顧卡片，依序呈現實際人身狀態、行動時間軸、目標、正確行動、危險行動、漏掉的必要決策、剩餘資源、迷思與反思問題，並提供建立新紀錄重練。

## 明確結局

- `EVACUATED`：已到達劇本指定的相對安全地點。
- `WAITING_RESCUE`：已降低暴露並穩定待救，但仍未脫離災區。
- `SHELTERED`：完成就地掩蔽，仍需等待官方後續資訊。
- `RESCUED`：只有劇本明示救援人員已接觸時才能使用。
- `FAILED`：危險行動造成不可接受的暴露或錯失關鍵安全條件。

完成學習任務不等於逃生成功。Android 的畫面與紀錄會顯示實際狀態，不再把所有完整流程寫成 `SUCCESS`。

## 已實作的因果能力

- 無關回答不推進狀態。
- 互相矛盾的決定先要求釐清。
- 危險行動可立即結束並鎖定本次演練。
- 行動可受電量、現場事實等前置條件限制。
- 資源可以因行動而消耗；條件不成立時不能假裝完成。
- 時間／拖延事件可以關閉原有撤離路線並切換任務。
- 引導選項可能包含危險行動，點選只填入，確認後才執行。
- 結束後另開新場次，不能修改已鎖定的結果。
- 劇本教育契約會檢查目標、迷思、反思、來源、因果節點、終止危險與實際人身狀態，避免新增只有故事文字但沒有訓練價值的劇本。

## 驗證

- JavaScript v3 runtime：受困待救、完成撤離、危急失敗、結束鎖定、資源不足、撤離窗口關閉、無關回答、矛盾回答與畫面引導選項案例通過。
- JavaScript v3 教育契約：5 個劇本的學習欄位、官方來源、因果分支、危險結局與人身狀態通過。
- 舊版共用火災：38 回合案例及既有瀏覽器 smoke test 通過。
- Android：21 個 JUnit 測試通過（含 6 個 `ScenarioRuntimeV3` 狀態與結構化回顧案例），`assembleDebug` 成功。
- APK：`android/app/build/outputs/apk/debug/app-debug.apk`。

本輪沒有 Android 真機，因此觸控、TalkBack、大字體、背景終止與實際 Room 寫入仍需真機驗收。
