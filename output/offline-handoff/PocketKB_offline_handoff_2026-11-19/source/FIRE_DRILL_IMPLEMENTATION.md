# 宿舍火災示範劇本 v2

實作日期：2026-09-12。這次只修宿舍火災；其他情境保留並標示為舊版，未宣稱全部災種已修正。

## 範圍與架構

唯一劇本來源是 `web-pwa/scenarios/fire-dorm.json`。Android Gradle 直接把此資料夾打包為 assets；網頁從同一檔案載入並離線快取。兩端分別由 `FireDrill.kt`、`fire-engine.js` 執行有限規則，並使用 `fire-cases.json` 的相同38回合驗證。

原計畫書以 LLM 驅動情境與評估。本次先建立可驗證的明確狀態管理；**尚未完成 LLM 理解與回饋整合**，不能以規則比對代稱語意模型。後續模型只能提出結構化行動候選與說明，需經狀態與安全邊界驗證，不能自行宣告完成或捏造救援到達。這是相對計畫書的架構調整，需在研究實作說明交代。

## 情境與因果

- 起始設定明確：模擬地址、A棟五樓503室、走廊已有濃煙、房門尚未關好、房內暫無明顯煙霧、手機在手邊。不是所有火災的通用路線。
- 關門 → 隔開走廊煙，進入求救階段。
- 分次完成聯絡119、地址棟別、樓層房號 → 模擬接線員取得定位資訊；不代表消防已到達。
- 留在已回報位置、保持通訊與依消防指示 → 完成教學決策；不代表實際安全獲救。
- 可修正的危險選擇在執行前攔截並保留進度；電梯、跳窗、穿越濃煙等選擇結束模擬。這些分支是教學回饋，不是物理火場或存活率模型。
- 門縫阻隔是手邊物品的輔助做法，不要求尋找濕毛巾，不以此延誤求救。

## 判定與互動契約

1. 觀察、詢問、提示不算完成行動。詢問目前提供本階段一般說明，**不是針對任意問題的AI答覆**。
2. 否定、疑問、假設、引用、已辨識矛盾與不確定語意不放行；無法理解時澄清，不當作使用者做錯。
3. 當前節點累積完成概念，同義詞不重複計分。所有必需概念必須完成；不靠關鍵字數量門檻。
4. 危險判定優先於正確行動。同句互相矛盾先釐清，不更新任何完成概念。
5. 只確認當前階段；同句包含後續階段行動會提示稍後確認，避免未取得現場資訊便一次灌入全部答案。
6. 引導選項只填入，不自動送出；其中包含非安全選項。提示分兩層，重复觀看不重複增加層數。
7. 成功／失敗之後，核心與送出入口都鎖定。重試產生新場次ID；網頁保存一次，Android同一場次只結束一次。
8. 初版只提供不限時學習模式。挑戰倒數、背景暫停與LLM語意能力留待後續，不沿用舊版30秒失敗規則。

## 紀錄

保存劇本版本、完整對話、已完成阶段與回顧。回顧包含已練習行動、未完成事項、被攔截風險與提示層數。Android以系統訊息儲存回顧，避免破壞既有Room資料庫；歷史畫面可展開回顧與對話。Room寫入序列化，避免場次尚未建立時插入訊息。

網頁完成與切換／重試時保存；強制關閉、重新整理的未完成場次尚不保證復原。Android程序被系統終止後也尚未提供恢復演練。這兩項要在長期研究收案前補齊。現有回應次數含觀察／提示操作，不可未經分離便當作研究中的自由文字回合數。

## 來源核對

- [逃生情境模擬](https://fsm.119.gov.taipei/w/fsm119/Fire_21103023325036374)：濃煙阻斷後退回關門、手邊物品阻隔與求救；確認路徑有煙／無煙的差異。
- [報案時機](https://fsm.119.gov.taipei/w/fsm119/Fire_21103023504653530)：受困後及早報案與位置資訊。
- [消防署受困待救宣導](https://www.nfa.gov.tw/cht/index.php?article_id=5720&code=list&flag=detail&ids=21)：不躲浴室、不為濕毛巾延誤避難。本次搜尋可讀到官方索引摘要，但直接開啟回傳502；正式內容審查需再次確認全文。
- [臺北市消防局逃生FAQ](https://www.119.gov.taipei/News_Content.aspx?n=6EEFD6ACA51B8E33&s=6FB1F286840AC217&sms=87415A8B9CE81B16)：僅引用不搭電梯、不強穿濃煙、不跳樓及位置報案相關項目，不將該頁所有段落直接轉成劇本。

地址、房號、接線員對話與教學分支是虛構設定。尚未經消防專業人員逐條審核，也未完成使用者實驗，不得宣稱已驗證教育成效。

## 驗證命令

在專案根目錄：

```powershell
node web-pwa/judge-smoke-test.js
python -m http.server 5173 --bind 127.0.0.1 --directory web-pwa
```

另一個終端執行（需可用 Playwright 與 Chrome）：

```powershell
node web-pwa/fire-browser-test.js
```

瀏覽器測試使用獨立無頭profile，不操作使用者瀏覽器資料。涵蓋38回合核心案例之外的實際完整送出、重試不同ID、唯一儲存、無橫向溢位、離線重載、草稿保留、無頁面錯誤。截圖位於忽略版控的 `web-pwa/test-results/`。

Android目錄：

```powershell
$env:ANDROID_HOME = 'C:/Users/Denni/Desktop/PocketKB_final/android/.tooling/android-sdk'
./.tooling/gradle/gradle-8.13/bin/gradle.bat --gradle-user-home .tooling/gradle-home testDebugUnitTest assembleDebug --console=plain
```
