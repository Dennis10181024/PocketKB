# PocketKB 災種 × 地點情境研究與建議矩陣

更新日期：2026-10-20
用途：規劃 PocketKB「線上模式情境演練」的內容範圍；本文件不代表程式已實作，也不取代主管機關即時警報或專業審查。

## 一、研究結論

1. **不能把同一個災種只做成一個地點。** 內政部消防署的地震宣導本身就區分居家、室外、百貨商場、停車場、電梯與捷運等情境，表示「所在位置」會改變可用掩護、移動限制、次生風險與撤離方式。[消防署：地震發生時應先以就地避難、保護身體為原則](https://www.nfa.gov.tw/pro/index.php?act=article&article_id=587&code=print&ids=113)
2. **建議用「地點原型 × 災害模組 × 條件變體」產生內容，而不是為每個組合複製一份劇本。** 例如「百貨公司」原型可共用樓層、電梯、手扶梯、人潮、廣播與出口資料，再疊加地震、火災、停電或暴力攻擊模組。這是本研究根據開發可行性提出的設計建議。
3. **土石流與大規模崩塌必須是高優先級。** 官方系統提供潛勢溪流、影響範圍、保全住戶、避難處所與道路封閉等位置相關資訊，演練重點應是警戒辨識、提早撤離、路線選擇與不返回危險區，而不只是災害已發生後的逃生。[農村水保署：防災整備系統](https://dfdpm.ardswc.gov.tw/dfdv/ArcMap/Default_Index.aspx)、[民眾防災指南](https://246.ardswc.gov.tw/SelfPreparedness/Guide)
4. **堰塞湖應納入，但屬低頻、高後果的專門情境。** 其風險分成上游迴水淹沒與下游壩體潰決，且從形成到破壞的應變時間可能很短；情境必須以個案警戒區、地方政府通知與撤離命令為準，不應讓模型自行推算安全時間。[林業保育署：堰塞湖警戒、監測及撤離資料](https://www.forest.gov.tw/file/66794)
5. **平時演練與災時指引應分開。** 演練可以呈現錯誤後果和分支；災時模式必須優先顯示官方警報、所在地風險、明確行動與聯絡方式。消防署「全民防災 e 點通」也把位置化警報、避難處所與不同災種須知視為核心能力。[消防署：全民防災 e 點通](https://www.nfa.gov.tw/cht/index.php?act=article&article_id=10263&code=print&ids=1520)

## 二、優先級定義

| 等級 | 定義 | 建議用途 |
|---|---|---|
| P0 | 共用底層能力，不是一個單獨劇本 | 先完成地點原型、狀態機、官方依據與驗收規則 |
| P1 | 高接觸機率、決策差異明顯、適合第一個研究版 | 第一批正式情境 |
| P2 | 重要但較區域性、專業性或需較多素材 | 第二批擴充 |
| P3 | 低頻高後果、受特定地理或專業條件限制 | 專題擴充；需主管機關或專家審查 |

優先級是產品開發排序，不代表災害嚴重度。

## 三、P0：可重用的地點原型

應先建成以下 16 種地點原型。每個原型至少要定義樓層／地形、出口、可掩護處、危險物、通訊、可見資訊、人群、弱勢者與可用資源。

| 地點原型 | 主要差異 |
|---|---|
| 1. 低樓層住宅 | 廚房瓦斯、家具、家人、前後門、鄰里 |
| 2. 高樓住宅 | 樓梯、電梯、垂直避難、高樓風勢、長距離撤離 |
| 3. 宿舍／租屋 | 不熟悉建物、室友、夜間、公共走廊、有限物資 |
| 4. 校園教室 | 教師指揮、桌椅掩護、班級點名、集體疏散 |
| 5. 校園特殊空間 | 實驗室、廚房、圖書館、禮堂、體育館各有不同危險物 |
| 6. 辦公室 | 隔間、機櫃、同事、訪客、高樓層與集合點 |
| 7. 百貨／超市 | 人潮、貨架、玻璃、手扶梯、廣播、多出口 |
| 8. 餐廳／夜市 | 明火、瓦斯、油鍋、擁擠與攤位阻礙 |
| 9. 電影院／KTV／旅館 | 陌生、昏暗、隔音、房間多、疏散方向不熟 |
| 10. 醫院／長照機構 | 行動不便者、醫療設備、不可自行快速撤離的人員 |
| 11. 工廠／倉庫／實驗室 | 危險物、機械、化學品、專業警報與區域管制 |
| 12. 地下空間 | 地下街、地下停車場、地下室；淹水、濃煙與停電風險 |
| 13. 公共運輸 | 捷運站、捷運車廂、火車站、列車、公車；需聽從行控與站務 |
| 14. 道路與車內 | 高架道路、隧道、地下道、橋梁、受阻車流與斷落物 |
| 15. 山區環境 | 山區聚落、山路、步道、露營地、溪谷、溫泉區 |
| 16. 海岸與河川環境 | 海灘、漁港、河口、堤防、河岸、低窪聚落、船舶 |

消防署將醫院、長照、百貨超市、學校等列為需重視防火管理的場所，支持將它們拆成獨立場所原型；這些場所不能只套用一般住宅逃生流程。[消防署：防火管理制度](https://www.nfa.gov.tw/cht/?code=list&ids=298)

## 四、完整災種 × 地點矩陣

### A. 地震

| 優先 | 地點情境 | 必須訓練的差異 |
|---|---|---|
| P1 | 住家－低樓層 | 就地掩護、家具掉落、瓦斯與火源、震後判斷是否撤離 |
| P1 | 住家－高樓 | 不搶搭電梯、玻璃與外牆風險、餘震、樓梯受損 |
| P1 | 學校－教室 | 趴下掩護穩住、聽從教師、震後疏散與點名 |
| P1 | 宿舍－夜間 | 黑暗、赤腳風險、室友、走廊掉落物、通訊不穩 |
| P1 | 百貨公司／超市 | 貨架及吊掛物、人群推擠、手扶梯、聽從廣播 |
| P1 | 辦公室 | 高樓隔間、同事受傷、電腦機櫃、集合點與家庭聯絡 |
| P1 | 戶外街道 | 招牌、玻璃、外牆、電線、橋梁與車流 |
| P1 | 捷運／火車 | 車廂內先穩住、不可自行開門進入軌道、聽從站務／行控 |
| P2 | 停車場／地下室 | 掉落物、停電、車道與火災／積水次生風險 |
| P2 | 電梯內 | 使用緊急通話、等待專業救援、不強行開門 |
| P2 | 開車途中／高架道路 | 安全減速停靠、避開橋梁與掉落物、保持救援通道 |
| P2 | 醫院／長照 | 病患移動限制、設備依賴、分區避難與工作人員指令 |
| P2 | 工廠／實驗室 | 機械停機、化學品洩漏、火災與區域隔離 |
| P2 | 山區／步道 | 落石、崩塌、道路中斷、通訊與定位 |
| P1 | 海邊／沿海地區 | 強震後立即評估海嘯風險並往高處／內陸移動 |

地震後家庭成員可能分散在工作地點、學校、購物場所等，NCDR建議預先約定會合點和替代路線；這也表示演練應把「震後聯絡與會合」納入，而不只模擬搖晃當下。[NCDR：家庭防災規劃資料](https://www.ncdr.nat.gov.tw/UploadFile/PageItem/240391377a704669bd5d39be3b49bdc9.pdf)

|---|---|---|

| P1 | 住家夜間臥室 | 警報聲、濃煙、低能見度、家庭成員與替代出口 |
| P1 | 高樓住宅 | 樓梯可用性、關門阻煙、不可搭電梯、受困待救定位 |
| P1 | 學校教室／宿舍 | 集體疏散、點名、不得返回、寢室夜間受困 |
| P1 | 百貨／電影院／KTV | 陌生出口、昏暗、人潮、廣播和工作人員指揮 |
| P1 | 餐廳／夜市 | 油火、瓦斯、多火源、壅塞通道 |
| P2 | 辦公大樓 | 高樓層、防火門、避難層、訪客與同事協助 |
| P2 | 醫院／長照 | 就地防護、分區／水平避難、行動不便者協助 |
| P2 | 工廠／倉庫 | 危險物、爆炸風險、廠區警報、禁止民眾自行處置化學火災 |
| P2 | 地下街／捷運站／地下停車場 | 濃煙、停電、向上疏散、不同出口狀態 |
| P3 | 森林／露營地 | 風向、火線、道路封閉、聽從封山與撤離命令 |

消防署提供地震、火災、土石流、颱風洪水等官方防災須知，所有劇本中的行動和提示應逐條連回這類官方材料，而非由模型自由生成。[消防署：防災須知](https://www.nfa.gov.tw/cht/index.php?code=list&ids=591)

### C. 颱風、強風與豪雨

| 優先 | 地點情境 | 必須訓練的差異 |
|---|---|---|
| P1 | 都市住家 | 門窗與陽台物品、停水停電準備、避免災中外出 |
| P1 | 低窪住宅 | 提前撤離、物資上移、停電與積水、不可只等水進屋 |
| P1 | 學校／工作場所 | 停班停課資訊、返家時機、留置與家人聯絡 |
| P1 | 道路／開車途中 | 積水、地下道、掉落物、強風與改道決策 |
| P1 | 山區聚落／旅宿 | 土石流警戒、預防性撤離、道路可能中斷 |
| P2 | 海岸／漁港／堤防 | 巨浪、海水倒灌、禁止觀浪與釣魚、船舶作業限制 |
| P2 | 戶外活動／露營 | 提早取消或撤離，不把「撐到活動結束」當作選項 |

消防署指出颱風可能同時帶來風災、水災、海水倒灌、土石流與坡地崩塌，因此颱風不應只是一個「關窗」劇本，而應作為多災種觸發器。[消防署：颱風篇](https://www.nfa.gov.tw/kid/index.php?article_id=1290&code=list&flag=detail&ids=659)

### D. 淹水／河川洪水

| 優先 | 地點情境 | 必須訓練的差異 |
|---|---|---|
| P1 | 低窪一樓住宅／社區 | 提前撤離或垂直避難、關閉電源、協助弱勢者 |
| P1 | 地下室／地下停車場 | 不下樓搶救車輛或物品、快速離開地下空間 |
| P1 | 道路／地下道 | 不涉水、不闖封鎖線、改道與車輛受困判斷 |
| P1 | 車內遇積水 | 及早離車到高處、避免等待車輛失去開門條件 |
| P1 | 河岸／堤防／溪邊 | 遠離暴漲河道、不觀浪、不撿拾物品 |
| P2 | 校園 | 低樓層設備、學生集體移動、校內垂直避難 |
| P2 | 商場／地下街 | 大量人流、廣播、地下出口可能受阻 |
| P2 | 避難收容處所 | 登記、藥物與輔具、家人聯絡、未解除警報不返家 |

教育部校園防災資料明確提醒，淹水時可垂直避難至較高安全樓層、關閉電源，且不可進入地下室或地下停車場搶救財物或泡水車輛。[教育部：校園防災知識卡](https://disaster.moe.edu.tw/MOE_FILE/daolpU/teachingMaterial/2024/TM20241211065922310/%E6%A0%A1%E5%9C%92%E9%98%B2%E7%81%BD%E7%9F%A5%E8%AD%98%E5%8D%A1%28%E4%B8%89%E6%8A%98%E9%A0%81%29.pdf)

### E. 土石流／大規模崩塌

| 優先 | 地點情境 | 必須訓練的差異 |
|---|---|---|
| P1 | 山區聚落住宅 | 黃／紅色警戒、保全住戶、預防性撤離、攜帶必要物品 |
| P1 | 山區道路／車內 | 路況不明、落石、道路封閉、不得穿越土石流潛勢溪流 |
| P1 | 溪谷／露營地／溫泉區 | 豪雨、溪水混濁或異常、快速離開河道與谷地 |
| P2 | 山區學校 | 集體撤離、家長接送受阻、替代避難場所 |
| P2 | 登山步道 | 定位、通訊、折返、避開崩塌坡面與溪溝 |
| P2 | 山區旅宿／民宿 | 遊客不熟地形、業者通知、團體撤離與道路中斷 |
| P2 | 下游橋梁／河道施工區 | 封閉管制、迅速離開河床、不得停留拍攝 |

土石流演練的核心是「警戒發布前後的行動鏈」：取得警戒、確認自己是否在影響範圍、選擇避難處所與路線、依地方政府指示撤離、待解除後才返回。[農村水保署：災害應變](https://246.ardswc.gov.tw/Old/DisasterApplication/Disasterdeal_Evacuation)、[土石流及大規模崩塌疏散避難作業規定](https://246.ardswc.gov.tw/files/%E4%BF%AE%E6%AD%A3%E8%A1%8C%E6%94%BF%E9%99%A2%E8%BE%B2%E6%A5%AD%E5%A7%94%E5%93%A1%E6%9C%83%E5%9C%9F%E7%9F%B3%E6%B5%81%E5%8F%8A%E5%A4%A7%E8%A6%8F%E6%A8%A1%E5%B4%A9%E5%A1%8C%E9%98%B2%E7%81%BD%E7%96%8F%E6%95%A3%E9%81%BF%E9%9B%A3%E4%BD%9C%E6%A5%AD%E8%A6%8F%E5%AE%9A.pdf)

### F. 堰塞湖

| 優先 | 地點情境 | 必須訓練的差異 |
|---|---|---|
| P2 | 堰塞湖上游聚落 | 迴水上升造成淹沒、道路中斷、提早轉移 |
| P2 | 下游河谷聚落 | 潰決洪水、極短警告時間、立即依命令撤往警戒區外或高處 |
| P2 | 下游道路／橋梁 | 不進入河床與管制區、不停留觀察、替代路線 |
| P3 | 河床施工／砂石作業區 | 通訊與警報接收、快速撤離機具、以人命優先 |
| P3 | 溪谷遊客／露營者 | 不熟悉警戒區、訊號不足、看到異常仍不可接近拍攝 |
| P3 | 山區學校／部落據點 | 集體疏散、弱勢者與交通載具、外地收容所 |

**內容安全限制：** 堰塞湖的壩體、蓄水量、溢流、降雨與上下游地形都是個案條件。演練可以教使用者辨認「接獲警戒後如何撤離」，但不可由通用 LLM 預測何時潰決、哪條路一定安全或何時可以返家；這些結論只能來自該次事件的權責機關資訊。[林業保育署：堰塞湖資料](https://www.forest.gov.tw/file/66794)

### G. 海嘯

| 優先 | 地點情境 | 必須訓練的差異 |
|---|---|---|
| P1 | 海灘／沿岸遊憩區 | 強震或海水異常後不等待、不拍攝，立即往高處或內陸 |
| P2 | 沿海住家／聚落 | 路線、步行疏散、攜帶必要物品、未解除前不返家 |
| P2 | 沿海學校／飯店 | 大量人員、遊客不熟路線、垂直避難備援 |
| P2 | 漁港／碼頭 | 港內船隻與岸上人員風險、遠離水域與港口 |
| P2 | 河口／河岸 | 海嘯可能溯河而上，逃生路線避免沿河川移動 |
| P3 | 近岸船舶／海上作業 | 依海嘯到達時間和權責單位指示處置，不套用岸上路線 |

中央氣象署指出，沿海遇較大地震或海水快速後退等徵兆應迅速往高處避難；海嘯可能多次侵襲，解除警報前不可返回港口或住家。[中央氣象署：海嘯防護](https://scweb.cwa.gov.tw/zh-tw/guidance/protection/118)、[海嘯來襲時建議作為](https://scweb.cwa.gov.tw/zh-tw/guidance/protection/226)

### H. 人為災害與公共安全

| 優先 | 地點情境 | 必須訓練的差異 |
|---|---|---|

| P2 | 工業區周邊化學事故 | 依風向和官方指示選擇撤離或室內掩蔽、關閉門窗與通風系統 |

| P1 | 捷運／車站暴力攻擊 | 反方向逃、利用堅固物掩蔽、安全後報警，不停留拍攝 |
| P1 | 校園暴力攻擊 | 逃離／鎖閉掩蔽／通報、安靜與位置保密、服從警方指示 |
| P2 | 商場／大型活動暴力攻擊 | 人潮、替代出口、避免逆流、可疑物與二次危險 |
| P2 | 車站／政府機關發現可疑物 | 不碰觸、保持安全距離、隔離區域、110通報 |
| P3 | 核子事故影響區－住家 | 室內掩蔽、疏散、碘片與飲食管制均依政府命令 |
| P3 | 防空警報－室內／戶外／車上 | 依所在地採不同就地避難方式，遠離窗戶與尋找最近掩蔽 |

瓦斯外洩的「禁、關、推、離」可直接做成住家和餐廳的分支判定。[消防署：液化石油氣事故與處理](https://mag.nfa.gov.tw/article.php?id=3654) 化學事故可能依暴露情形採撤離或室內緊閉門窗的就地避難，不能固定只教一種行動。[化學物質管理署：毒化災疏散避難原則](https://www.cha.gov.tw/dl-3454-8d7ace83d59c470b9fe12451a4e66274.html) 暴力攻擊則可依警政署的 RUN、HIDE、TELL（跑、躲、說／報）原則設計。[警政署：民眾自我安全防護常識彙編](https://www.npa.gov.tw/ch/app/data/doc?detailNo=1402849470051258368&module=wg071&type=s)

核子事故中的掩蔽、疏散、服用碘片、食物及飲水管制等都必須依中央災害應變中心命令，App 不得自行推薦使用碘片。[核安會：核子事故民眾防護行動規範](https://erss.nusc.gov.tw/law/LawContent.aspx?id=FL036416)、[核安會：防護資訊](https://www.nusc.gov.tw/%E4%BF%9D%E5%AE%89%E6%87%89%E8%AE%8A/%E6%B7%B1%E8%80%95%E5%AE%A3%E5%B0%8E%E9%98%B2%E8%AD%B7%E8%B3%87%E8%A8%8A--5484_5489_5506.html)

### I. 複合災害

複合災害不應只是把兩個標題接起來，而要讓前一災害改變後一災害的狀態與可用路線。

| 優先 | 組合與地點 | 主要連鎖 |
|---|---|---|
| P1 | 地震 → 住家瓦斯外洩／火災 | 搖晃後火源、電氣、通風、撤離路線改變 |
| P1 | 地震 → 百貨停電與人潮 | 照明消失、手扶梯停止、出口壅塞、廣播中斷 |
| P1 | 地震 → 沿海海嘯 | 先保護自己，再立即由沿海往高處或內陸移動 |
| P1 | 颱風豪雨 → 山區土石流 | 警戒升級、道路封閉、預防性撤離時間窗縮短 |
| P1 | 豪雨 → 都市淹水 → 停電 | 地下空間、電擊風險、垂直避難與通訊 |
| P2 | 地震／豪雨 → 堰塞湖 → 下游潰決風險 | 個案警戒、上下游不同撤離路線、不得進入管制區 |
| P2 | 地震 → 工業區化學洩漏 | 原本集合點可能在下風處，需依官方指示重新選擇掩蔽／撤離 |
| P2 | 颱風 → 海水倒灌 → 沿海社區淹水 | 海岸、河口、低窪住宅的多路徑受阻 |
| P2 | 山區地震 → 崩塌 → 受困與斷訊 | 道路中斷、定位、物資、等待救援而非冒險穿越 |
| P3 | 核子事故＋颱風／交通中斷 | 疏散路線、掩蔽時間與收容安排高度個案化 |

## 六、避免情境數量失控的資料設計

不建議把「地震－學校」「地震－住家」「地震－百貨」各自寫成完全獨立、互不共用的程式。建議分成三層：

```text
地點原型（Location Profile）
  ├─ 樓層、出口、掩護、危險物、人群、弱勢者
  ↓
災害模組（Hazard Module）
  ├─ 地震、火災、洪水、土石流、堰塞湖、海嘯、化學事故…
  ↓
情境變體（Scenario Variant）
  ├─ 日夜、是否獨處、出口受阻、通訊、受傷者、警戒階段
```

例如「地震－百貨公司」不是單純換文案，而是：

- 地點原型提供貨架、玻璃、手扶梯、電梯、廣播、出口和人群。
- 地震模組提供搖晃、餘震、掉落物、停電和震後檢查。
- 變體決定所在樓層、是否停電、同行者是否受傷、哪個出口被封閉。

每個完整情境至少應有：

- 1 個明確起始事件。
- 5 個以上可觀察的環境事實。
- 5～8 個關鍵決策。
- 3 條以上可行分支。
- 2 個以上環境變化事件。
- 安全、部分完成、危險／失敗等不同結果。
- 1 組官方來源對照。
- 線上自然語言測試與離線規則測試。

## 七、內容審查與安全邊界

1. **所有安全行動由規則與已審查資料決定，LLM只能理解語句和敘事。**
2. **區域性災害不得泛化。** 土石流、堰塞湖、海嘯、核子事故必須先確認使用者是否位於相應警戒／潛勢區。
3. **即時資訊不得由模型生成。** 警戒等級、封路、避難所、海嘯抵達、堰塞湖狀態與解除命令只能由官方資料或演練明示的虛構資料提供。
4. **不要讓使用者在災時做高認知負荷的遊戲。** 真實災時模式只顯示立即行動、官方警報、定位、離線指引與求援。
5. **弱勢使用者不能只作為劇情道具。** 醫院、長照、兒童、身心障礙者與外籍人士的情境需要對應機構或專家審查。
6. **堰塞湖與化學事故不提供自行研判的安全距離。** 只訓練接收警報、辨識管制、撤離／掩蔽和等待解除。
