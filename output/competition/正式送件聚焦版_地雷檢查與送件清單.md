# PocketKB Edge｜正式送件聚焦版

## 主辦單位四項地雷檢查

1. **技術太多：已收斂。** 技術頁只保留 Edge Hardware、Speech Perception、Reasoning＋Workflow、Restricted Runtime 四層，而且每一層都對應斷網、無法打字、自主推進或安全控管的必要問題。
2. **目標不清楚：已改成一句話。** 讓一棟宿舍在斷網與無法打字時，仍能從警報或求救走到下一個已驗證的安全行動。
3. **什麼都想做：已限定 MVP。** 一棟宿舍、煙霧與停電兩種訊號、食品／飲水期限與手電筒兩類物資、一張逃生圖、一個模擬照明工具、一個台語長者情境。
4. **過度追求完整：已分清現況與競賽新增。** 現有成果只有 Android／PWA 規則演練原型；語音 Agent、AIoT、NVIDIA 部署與量測都列為入選後工作。

## 評審應在 30 秒內理解的內容

- **問題：** 災前準備可能失效，災時人又可能因恐慌、長者操作障礙、濃煙或停電而無法打字與判斷。
- **解法：** 在地 Agent 主動觀察、規劃、執行、驗證；失敗就換路線、換工具或交由人員接管。
- **創新：** 台灣華語／台語語音、離線邊緣推論、受限工具執行與可稽核的任務處理流程組成同一個災時系統。
- **展示：** 平時巡檢流程與災時台語長者求救應變流程，各自從觸發到驗證完整重播並量測。
