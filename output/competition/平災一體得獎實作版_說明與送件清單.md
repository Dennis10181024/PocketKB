## 一句話定位

PocketKB Edge是平災一體的在地自主Agent：平時主動監測環境、防災物資與設備並追蹤改善；災時以台灣華語／台語協助逃生、安撫、照明與通報，斷網時仍在場域內運作。

## 為什麼這版最有競爭力

1. **Agent自主性清楚**：時間、感測器或語音事件主動啟動，不等待使用者提問。
2. **Edge具有必要性**：環境、物資、圖資、語音與事件紀錄留在場域，外網中斷仍可服務。
3. **企業價值可量測**：同時降低巡檢工時、逾期任務與災時形成可用行動的時間。
4. **NVIDIA整合有責任分工**：Nemotron負責理解與tool call；NeMo Speech負責ASR／TTS；NeMo Agent Toolkit負責workflow與評估；NemoClaw／OpenShell負責受限runtime。
5. **安全邊界可查證**：低風險白名單可自動執行；中風險需核准；高風險拒絕並轉人工。

## 最小可行產品範圍

只承諾一棟宿舍與下列內容：

- 4類環境／設備狀態：煙霧或溫度、CO、感測器心跳、輔助照明。
- 4類防災物資：飲水、即食食品、手電筒電池、長者／助聽器備用電池。
- 2個完整情境：平時自主巡檢、災時台語求救與路線重規劃。
- 1個模擬設備閘道：照明、通知、工單與狀態回傳。
- 1套封存測試集：安全120則、多步任務30個、台灣華語／台語噪音音訊。

不把攝影機辨識、所有災種、真實119自動通報、法定消防設備控制與完整社區部署列入第一版承諾。

## 開發優先順序

### P0｜入選前一定完成

1. `incident_state`與`readiness_state`共用任務狀態格式。
2. 環境、物資、路線、通知、照明、TTS等工具契約。
3. 模擬感測器與設備閘道，可注入過期、低電量、失聯、煙霧及逾時事件。
4. Observe→Plan→Act→Verify→Replan閉環與人工接管。
5. 120則安全情境、30個多步任務及可重播工具軌跡。

### P1｜取得DGX Spark後完成

1. 部署主辦環境支援的Nemotron與OpenAI-compatible本地端點。
2. 將NeMo Agent Toolkit接到既有工具契約並跑evaluation／profiling。
3. 部署NeMo Speech ASR／TTS，測試台灣華語、台語、長者及警報噪音。
4. 依官方支援方式鎖定NemoClaw／OpenShell sandbox、policy與inference route。
5. 量測GB10 unified memory、TTFT、tokens/sec、1人／4人p50／p95及故障回復。

### P2｜時間允許再做

- 條碼／OCR實體掃描與溫濕度感測器。
- 第二種建物圖與第二個場域。
- 台語語料擴充、客語高風險詞與更多長者測試。
- 實體輔助導引燈；仍不接管法定消防設備。

## 兩段決賽Demo

### Demo A｜平時自主巡檢

系統時間事件觸發→發現即期食品、低電量與CO感測器失聯→Agent交叉查詢→建立輪替、補充與維修任務→管理者處理→重新掃描與讀值→全部達標才結案。

### Demo B｜災時自主應變

火警觸發→長者以台語求救→本地ASR取得位置→Agent建立疏散與通報任務→煙霧使原路線被規則否決→改走替代路線→台語TTS安撫並要求回讀→啟動模擬輔助照明→確認回傳→建立災後補貨維修任務。
