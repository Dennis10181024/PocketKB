# 步驟 5.5b 草稿修訂

草稿，待人工審查。這次依任務中列出的交付要求檢查五包。先前提到的 5.5b 全文未出現在目前可見對話，因此以下是這次採用的具體驗收項目。

## 結局等級與傷勢清單

Web 和 Android 的五個內建包都使用 fromInjuries。採本場本人傷勢清單的最高等級。積分仍記錄暴露和延誤，同伴傷勢列於清單。危急終止的本人等級維持「不評定」。

| 草稿的亂玩向量 | 修訂後本人等級 | 說明 |
|---|---|---|
| 宿舍火災 | 重傷 | 清單有最高級的呼吸困難事件 |
| 學校地震 | 中度 | 依已記錄的中度傷勢事件 |
| 捷運 | 輕傷 | 本人各事件分級為輕傷 |
| 淹水 | 中度 | 本人有中度小腿撞傷事件 |
| 颱風停電 | 無傷 | 本人未記錄受傷，小晴的手指燙傷仍列於清單 |

## 題幹和選項

地震與火災保留必要現場線索。改寫宿舍封門縫、捷運對講與車門、淹水電箱與高處定位、颱風照明、電器和食品等容易複述正解的題幹。用選項執行的效果核對判定。淹水迷思改為誤以外表乾燥可恢復供電，沒有把「通知房東請專人」當成危險。停電迷思清楚指出尚留另一個發熱電器待復電。
