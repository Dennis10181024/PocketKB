# 步驟 1.4｜九劇本與分級結局

範圍為六個現有劇本與三個新劇本大綱。以下為演練規格與待校準案例，步驟 2 建立共用機制並驗收六個既有劇本，步驟 3 才撰寫三個新劇本的 JSON。所有通報、警戒、現場與救援均為模擬。

## 狀態機如何決定結局與傷勢

- **自行撤離（撤）**：已確認的路線可用，玩家自行抵達指定相對安全區。避開危險、送出通報或單純移到高處，都不能代替抵達事件。
- **安全待救獲救（救）**：已建立安全待救條件，且劇本發出有效的救援接觸及接手事件，沒有觸發已定義的延誤條件。
- **延誤後獲救（延）**：救援已接觸及接手，且有可追溯的延誤事件，例如重新傳送定位、原路封閉後改等候區。延誤狀態本身不等於受傷。
- **危急失敗（危）**：立即終止動作或已定義的危急護欄命中。傷勢顯示「不評定」，不結算現實傷害。保留既有暴露及起始傷勢供回顧。玩家主動退出另記，結局與傷勢留空。穩定待救維持進行中，直到救援接手或另有終局事件。

**開場固定。** 既有六劇本以目前 JSON 開場為基準，新三劇本以本文件的基準開場為準。開場固定 variant_id、initial_state（含地點、路線、危害旗標、暴露與資源）、scenario_version、engine_version。預設固定使用 base，其他變體由課程或玩家於開場明確選定，落 log 後不可改換。路線後續改變由已列事件唯一決定。相同開場快照及相同原文輸入序列必得相同結果；同一版本的相同原文由固定的解析與消歧規則產生相同提交決策。GPT 可提供理解候選和敘事，但不可作為接受傷害／安全動作的必要條件，或改變已提交動作、事件或結局。傷害、路線變體、救援與分級不使用隨機數、牆鐘或模型輸出。

**暴露計算。** 暴露項目分開累加，最大傷害項決定結局等級，同分以固定項目順序，回顧保留全部原因。0 為無傷、1–2 為輕傷、3–4 為中度（需送醫）、≥5 為重傷（需要住院長期治療）。住家腿部外傷開場為 1，結局仍為 1 且其他傷害項全為 0 時顯示「傷勢未加重」；若同項新增至 2 則為輕傷。這些是待校準的劇本分數，無醫療或真實暴露量換算。重傷具名案例僅保留煙吸入機制。已有暴露不隨急救、通報或重畫畫面扣除。

**結算順序。** 原文比對 → 立即終止護欄（優先，寫 NOT_ASSESSED 並停止，不執行本輪傷害事件）→ 更新已確認動作和事件 → 扣資源、加暴露、歸因 → 到達／救援接手才分級。終局不評定和未結局 null 分開，舊場次缺值不得補成無傷。只有表列條件能產生傷害。耗電及延誤另記，不參與傷勢。攔下、假設、無效文字與介面閒置不產生身體暴露。計分事件一律以 requestId 及 occurrenceId 去重，未列入的危險判定仍寫 log。

**救援與恢復。** 測試版在玩家完成有效通報、已到劇本指定相對安全待救點且終局護欄未命中後，於下一個「確認保持在該處待救」的已結算決策送出固定的模擬接觸及接手。通報重送、改派或命中表列延誤動作才標記延誤。相同 requestId 的網路重試不算重送。H2、W4、L4、B1、P4、T4、Q2 及 F5 第一次均設延誤；S2 設疏散延誤。正確流程不必等待真實秒數。累積事件的恢復路徑須完成該劇本安全及通報條件，無法達成則維持待救或按已設定護欄停止。救援節拍只是可重現的教學設計。

**回顧與急救。** 立即終止由引擎顯示人工撰寫的一至兩句第一人稱當下風險，回顧明說「這個行動在真實情況下可能造成嚴重傷害，所以演練停止」，並列具體動作與替代做法。輕傷結局可接相應且可跳過的急救點，先通過安全及教材適用條件；結局鎖定後再做，不覆寫傷勢。中度或重傷由劇本呈現救護評估，不要求民眾自行處理。回顧追溯回合、動作或事件、暴露增量及可改採的做法。

### 最佳結局與最短正確決策序列

「最短」指基準開場通過結局守門所需的安全決策，合併同一決策內的通報欄位。保留已設計的 NPC 錯誤點和後續情緒點，兩者不得合併。流程只列會變更狀態的步驟，無效回合與建議句都不必觸發。箭頭後的接手或抵達是固定引擎事件。本表描述新版契約的預期最短路徑，需在步驟 2／3 以可執行測試證明。

### 輕傷後急救與立即終止文案

宿舍 F4 只接消防署燒燙傷宣導中與已確認輕度熱接觸相符的選擇。其餘八個輕傷路徑的機制是跌倒、絆倒或碰撞，使用外傷卡，確認現場安全，按場景已有的出血資訊選擇直接加壓或覆蓋保護，未確認持續出血時不強制加壓；懷疑骨折、不宜移動或需更進一步照護則回報並依救護指示。捷運原有傷者救護點另計 NPC，不納入玩家傷勢。教材適用性由專業審查確定。 [消防署止血、包紮與骨折固定](https://ebook.nfa.gov.tw/1140527/files/basic-html/page142.html) · [消防署燒燙傷宣導原則](https://www.nfa.gov.tw/upload/pro/attachment/8fe7c0c47c125cb6682ed0924a38ecab.pdf)

## 待查證與發布驗收

- 固定場景的事件點、可見線索、退出／替代動線、接手條件與適用範圍待內容審查。來源可支持傷害機制，不能直接證明表中的時間、場地、外傷或臨床等級。
- 住家開場已受傷，正確路徑不增加外傷。「傷勢未加重」屬最佳展示狀態，底層仍保留原始輕傷，統計單獨計數。輕傷及中度案例必須可用具體失誤重現。
- 搖晃或落物、淹水濕階、路肩碎石、捷運通道障礙、颱風照明、震後散落物與隔煙延誤皆須在配置時逐一審查。三個新場地的正式通報、救援、急救及管理者職權依 1.3 的來源限制，缺官方依據一律待查證。
- 對每個傷害事件跑命中、前置條件缺一項、重送、不同事件同輪及立即終止優先。固定 variant_id 下同輸入重放需逐事件一致，最佳路徑無新增傷勢。驗證學校命中 S1 後，帶隊分支會攔下返教室，S2 不再成立。
