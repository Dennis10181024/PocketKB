# Android 離線知識查詢介面提案

狀態為待兩位組員審查。基線是 PocketKB `86231ed657611ea1270d3560ab994d48a959c05a`。

## 共用呼叫

兩個入口共用 Kotlin 查詢與同版來源閱讀。下列是欄位與行為提案，實作的 Kotlin 型別由雙方審查後決定。

| 呼叫 | 最小語意 |
| --- | --- |
| `search(request)` | 請求帶 `request_id`、`mode`、`mode_epoch`、`purpose`、查詢文字，以及使用者明示的災種、階段與地區。結果包含狀態、同一請求身分、有效資料集的版本與世代，以及各筆來源引用。 |
| `openCitation(citation)` | 只從當前會話中仍有效的搜尋結果開啟。用資料集、資料包摘要、來源 ID 與版本、片段 ID、定位及摘要解回同版的本機原文。版本切換或已知撤回會使舊引用失效。 |

| 查詢狀態 | 介面行為 |
| --- | --- |
| `OK` | 顯示通過當前用途及適用條件的來源卡。 |
| `NO_MATCH` | 有效目錄完成查詢但沒有適用命中。可重新搜尋或瀏覽。 |
| `CLARIFICATION_REQUIRED` | 缺少會改變適用性的明示條件。指出需要補充的條件。 |
| `INSUFFICIENT_EVIDENCE` | 資料不足、過期或衝突，無法支持判斷。保留能獨立查證的來源。 |
| `LOCAL_UNAVAILABLE` | 必要的本機資料或閱讀資產無法使用。對應內容停止呈現。 |

沿用 `RagEngine.retrieve()` 做候選排序。准入、撤回、地域及用途限制在發卡前核對。同類前三筆補位不適用於共用查詢。即使模型未安裝或失敗，來源卡仍可獨立使用，模型狀態另記。

## 入口及分工

- **離線輔助**負責資料包、查詢驗證、來源卡、同版閱讀器與災時查詢。第一個功能 PR 使用自撰合成資料驗證，不發布正式防災內容。
- **情境演練**負責何時開放查閱及其揭露範圍、導回原決策點與 FSM 回歸。可先以假查詢服務與合成資料驗證邊界。
- **共同決定**資料目錄的版本與撤回責任、演練交付給查詢端的唯讀條件，以及共用導航由誰接線。
- 災時／災後入口建立獨立會話。查詢端不接收演練歷史、推測的地點或未揭露狀態。離開、取消或換模式使舊回應失效。查詢及來源閱讀皆在裝置上完成。

## 首批驗收

- 以同版、同查詢及同准入條件比對兩入口的預期命中與來源定位。繁中別稱、真正無命中及回跳保留原查詢。
- 區分錯版、錯摘要、撤回、資料不足及本機讀取失敗。模型缺席仍能查閱。正式來源由用途准入及審查安排。
- 演練中搜尋、取消、換模式及晚到回應都不能改寫原決策點、劇情、評分或重播。
- 產品 PR 另留 Android 啟動、飛航冷啟動、同版讀取及必要相鄰回歸的實測紀錄。
