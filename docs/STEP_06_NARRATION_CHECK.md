# 步驟 0.6 · 敘事檢查與來源

- 檢查文字的指令片段，以句號、問驚嘆號、分號或換行切段。遇到「建議」「請先」「不妨」等明示建議語氣時，程式查對當前階段可用且未列為危險的動作名稱或劇本匹配式。另對搭電梯、跳窗、涉水等顯式危險指令設攔截。警告式的否定短句及一般敘事不在這項檢查範圍。
- 第一段不符合時，按剩餘 8 秒期限及呼叫上限嘗試重生一次。兩次皆不符合、出錯或逾時，保留引擎已算出的狀態，以引擎結果或固定文字呈現。這是敘事降級，與行動判讀整輪轉規則是不同欄位。
- 回饋來源由程式從新事件對應的動作、惡化事件及規則提供的風險警示取得。模型無來源欄位可以指定。六個劇本的每個來源 ID 已檢查存在，來源內容與細部教學動作的適用性仍需專業核對。
- 指令句式檢查對不含提示詞的隱晦建議、同句混合多行動、否定句中的其他指令，以及陳述句內的虛構後果覆蓋有限。實測已發現動作語意不一致的例子，見 [重測報告](DIAGNOSIS_GPT_LIVE.md)。
