# PocketKB 選擇題盲測題本

草稿，待人工審查。僅供組員試答。

正式三劇本請使用[方案 B 題本](BLIND_OPTION_TEST_PLAN_B.md)，此份保留五個劇本供開發試答。

各題以當下資訊選一項最適合的做法，在答案欄填 A、B、C 或 D。可跳過任何題目。看完題本前請先不要試玩或查看答案。捷運一節涉及突發攻擊與人群恐慌，若感到不安可跳過整節。
