# PocketKB 防災前後測題庫

**草稿，待人工審查。** 本檔含答題原則與答案，供教授及施測主持人使用。正式施測時，只發當次版本的題幹與選項。

五個劇本每個六題，共 30 個知識題目。每題有等原則的 A／B 情境題幹，搭配四個共同選項（1 個正確、3 個干擾選項）。預計用 A→B 與 B→A 平衡前後測；延遲測須先定案第三套題幹或重測方案。試測每題兩版答對率與語意，不能假定兩版難度已等化。主持人也可在保留題號與答案對照下調整選項位置。

正式施測以納入的劇本範圍計分，正確 1、其他作答 0、未作答與退出各自標記。捷運題內容涉及突發攻擊，讀題前提示並允許跳過。前後測題幹換用新場景或問原理，避免重複 App 選項文字。

### 01｜煙熱判斷

- A 版：旅館房門另一側有濃煙，門也發熱。我該怎麼判斷能否經原走道撤離？
- B 版：補習班通往出口的走道已出現濃煙和熱氣。該怎麼判斷這段路？

- 甲　濃煙和熱使眼前走道不宜通過
- 乙　出口離得近，快走幾步仍來得及
- 丙　看得見出口燈就能走
- 丁　伏低身體後，原走道就能通過

主持人答案為 **甲**。評量原則為「煙熱判斷」。依據 F1、F2。

- 乙｜用距離估算風險，容易低估吸入高溫濃煙的速度。
- 丙｜把地標可見當成整條動線可通過。
- 丁｜知道煙往上升，便誤把低姿勢當成穿越濃煙的保證。

### 02｜隔煙目的

- A 版：公共走道煙很重，房內尚未充滿煙。保持門關閉主要在爭取什麼？
- B 版：樓梯動線已失去通行條件，同行者問為何要保留一扇完整關閉的門。對室內最直接的效果為何？

- 甲　關好門能把房內既有濃煙排出去
- 乙　等門冷下來，就能確定外面可走
- 丙　讓走道濃煙比較慢進到房內
- 丁　把室內完全隔絕煙氣

主持人答案為 **丙**。評量原則為「隔煙目的」。依據 F1。

- 甲｜把遮斷煙的進入和排出室內既有煙氣混為一談。
- 乙｜把一個門板溫度線索當成可以確認整段煙況的依據。
- 丁｜看見關門後煙量變小，容易以為一般門可以完全密封。

### 03｜受困空間

- A 版：旅館房外已無安全通路。暫時等待救援的空間，最需要哪些條件？
- B 版：大樓走道被濃煙阻斷。要選一處暫時避難，哪個條件最重要？

- 甲　有水可把毛巾弄濕，就適合留下
- 乙　靠近樓梯會方便接應
- 丙　越封閉、外面越聽不到就越安全
- 丁　能隔煙並向外確認受困位置

主持人答案為 **丁**。評量原則為「受困空間」。依據 F1。

- 甲｜把濕毛巾的效果高估，因而把有水視為最重要條件。
- 乙｜把消防員的可能動線當成安全等待條件，忽略附近的煙。
- 丙｜把隔煙與完全封閉混為一談，忽略保持對外聯絡。

### 04｜避免搭乘電梯

- A 版：辦公樓收到火警通知，電梯的樓層顯示仍正常。這能證明它可供逃生嗎？
- B 版：商場疏散時有人指出電梯內燈仍亮。哪個判斷較妥當？

- 甲　有同伴順利搭完，下一趟也可用
- 乙　有電也無法證明能安全撤離
- 丙　門能開關就表示電梯仍可疏散
- 丁　電梯照明正常就可用來疏散

主持人答案為 **乙**。評量原則為「避免搭乘電梯」。依據 F2。

- 甲｜用別人的一次結果推論火勢和設備不會再變化。
- 丙｜把眼前門片正常當成整段運行和出口安全的證明。
- 丁｜平常用指示燈判斷設備是否正常，忽略火災時可能突然停電。

### 05｜濕布的限制

- A 版：有人表示只要隔著濕布呼吸，就能穿過火場濃煙。這個說法忽略什麼？
- B 版：房內沒有現成毛巾。有人想穿過煙區去找，因為相信沾水後能阻擋有害氣體。哪個判斷較妥當？

- 甲　折厚一點就能把有害氣體擋下
- 乙　濕布無法濾掉濃煙裡的毒氣
- 丙　布保持濕潤就能防住毒氣
- 丁　聞不到焦味，就表示濕布已有效

主持人答案為 **乙**。評量原則為「濕布的限制」。依據 F1、F4。

- 甲｜把物理厚度和真正的濾毒能力混為一談。
- 丙｜把水分能降溫的直覺誤套在有毒氣體。
- 丁｜把氣味變弱當成吸入有害氣體已停止。

### 06｜具體通報

- A 版：民宿內有三人無法離開，接線員還不知道地點。哪一組資訊較有助於定位？
- B 版：租屋處有一人受困，門外已有煙。通話剛接通時哪種說法較有助於救援？

- 甲　先報姓名與來電號碼，地點稍後補
- 乙　先報哪裡冒煙，再等派人查位置
- 丙　說附近店家及可辨識地標
- 丁　報出門牌、樓層、人數及受困情形

主持人答案為 **丁**。評量原則為「具體通報」。依據 F3。

- 甲｜把留下回電方式誤認為等同完成現場定位。
- 乙｜以為先講災情就能出勤，忽略派遣仍要知道人在哪裡。
- 丙｜地標容易辨識，報案者可能以為接線員不用地址和樓層也能找到人。

## 學校地震

### 07｜遠離落物

- A 版：實驗教室開始晃動。在不必穿越教室的範圍內，哪個位置的落物風險最低？
- B 版：圖書室突然搖晃，附近東西開始滑落。哪個相鄰位置最有遮蔽？

- 甲　就近的穩固桌面下方
- 乙　離櫃子很近的窄角落
- 丙　窗旁伸手可及的桌邊
- 丁　門框下方的開口處

主持人答案為 **甲**。評量原則為「遠離落物」。依據 E1。

- 乙｜空隙看起來能擋落物，卻可能在高家具移動或倒下時受波及。
- 丙｜光線充足又看得到外面，容易把可觀察性當成防護。
- 丁｜部分人沿用「門框最牢」的舊印象，忽略現場缺乏上方遮蔽。

### 08｜穩住掩護

- A 版：就地躲在堅固桌下時，抓住桌腳有何用途？
- B 版：晃動中發現掩護物逐漸滑移。姿勢中的「穩住」主要要處理什麼？

- 甲　抓住桌腳可減少桌上物品滑落
- 乙　讓桌子固定不動，不再左右移位
- 丙　桌子移動時仍能跟著維持遮蔽
- 丁　抓穩自己便不用護頭

主持人答案為 **丙**。評量原則為「穩住掩護」。依據 E1。

- 甲｜看到桌面因抓穩顯得比較穩，容易把個人的防護動作當成控制桌面物品的辦法。
- 乙｜把「抓穩」理解為靠手力阻止家具移動。
- 丁｜以為抓住物體即可免受所有落物傷害。

### 09｜餘震與暫停移動

- A 版：研討室準備疏散，還沒離開原地就又開始搖晃。適合在什麼情況下恢復移動？
- B 版：活動中心第一次晃動已停，準備出門時又開始晃。哪個才是重新確認動線的時機？

- 甲　看到出口就放慢腳步繼續走
- 乙　扶牆等晃動稍小就出發
- 丙　先恢復就地防護，停晃後再判斷
- 丁　觀察前一批行動，再跟著一起撤離

主持人答案為 **丙**。評量原則為「餘震與暫停移動」。依據 E1、E2。

- 甲｜已開始往出口時容易延續原決定，認為放慢就足夠。
- 乙｜強度下降容易被當成停止，忽略仍有落物與失衡風險。
- 丁｜把他人行動當成新的震況判斷。

### 10｜疏散秩序

- A 版：老師確認這段樓梯可通行。哪種安排能降低後方人群跌倒的機會？
- B 版：大樓演練中樓梯轉角視線短。團體通過轉角時怎麼降低踩踏風險？

- 甲　護住頭頸，保持間距依序下樓
- 乙　各自下樓，再在出口會合
- 丙　到轉角快速超過慢的人，讓出動線
- 丁　貼近前方的人，保持隊形

主持人答案為 **甲**。評量原則為「疏散秩序」。依據 E2。

- 乙｜平日自行行走可行，大量人員在窄處合流時卻容易擁堵。
- 丙｜以為更快代表更流暢，忽略超越會增加交錯。
- 丁｜把跟隊與保持貼身混為一談，忽略停步時的追撞。

### 11｜戶外落物

- A 版：地震後來到有外牆、路燈和空地的校園廣場。哪處更適合短暫集合？
- B 版：樓內人員離開後在校園找集合點。選點最好考量什麼？

- 甲　靠外牆集合，留中央給其他班級
- 乙　開闊且避開外牆、線路的區域
- 丙　在近出口的遮棚等候
- 丁　站到路燈旁，用固定地標清點

主持人答案為 **乙**。評量原則為「戶外落物」。依據 E1、E2。

- 甲｜用邊緣讓路符合平日秩序，卻忽略外牆可能掉落物件。
- 丙｜遮棚能避雨也便於會合，容易忽略近建築的落物風險。
- 丁｜固定地標方便找人，卻也可能是倒落物附近。

### 12｜清點與通報

- A 版：集合後發現同桌未到，但不知道是否已隨別班撤出。先採取什麼做法？
- B 版：社團撤離後有位同伴沒有簽到，大家不知道他在哪。哪項能避免再有人進去涉險？

- 甲　先請附近班級自行找，再一起回報
- 乙　等同桌回訊息後再告訴負責人
- 丙　先讓熟悉教室的同學回去看看
- 丁　向現場負責人回報並核對名單

主持人答案為 **丁**。評量原則為「清點與通報」。依據 E2。

- 甲｜多人找看似較快，卻讓搜索與清點失去統一資訊。
- 乙｜怕誤報或太早打擾，容易延後失聯核對。
- 丙｜熟人容易找到路，但可能讓更多人進入未確認安全的建築。

## 捷運車廂

### 13｜安全距離與撤離

- A 版：車站突發騷動，最近的人群來向混亂，另一條通道確認可遠離危險。優先目標為何？
- B 版：大眾運輸場站傳來警訊，站務指出有可通行出口。何者應優先？

- 甲　先沿當下確認可通行的路線離開
- 乙　先到平常使用的出口，再依人流離開
- 丙　在原地觀察情況後再決定
- 丁　先找到散在附近的同行者，一起走

主持人答案為 **甲**。評量原則為「安全距離與撤離」。依據 M1。

- 乙｜熟悉動線帶來確定感，可能忽略當下站務指定的安全出口。
- 丙｜資訊不明時想看清楚，但已有安全路線仍停留就增加暴露。
- 丁｜想照顧同伴很合理，卻容易把會合放到脫離當前風險之前。

### 14｜躲避時降低聲響

- A 版：附近無法安全撤離，目前已躲在能遮蔽的位置。怎麼使用手機較妥當？
- B 版：暫時沒有安全路線，旅客在隱蔽處等待。哪種手機處理方式較適合？

- 甲　保持手機原設定，主要靠遮蔽物擋聲
- 乙　只關通知音，保持通話擴音方便求助
- 丙　切成震動，保留來電提醒等待聯絡
- 丁　關閉手機，保持安靜等待安全時機

主持人答案為 **丁**。評量原則為「躲避時降低聲響」。依據 M1。

- 甲｜把有東西隔開視線，也當成足以隔絕提示音。
- 乙｜想讓電話另一端掌握狀況，忽略對話與擴音會暴露位置。
- 丙｜容易把沒有鈴聲當成完全無聲，忽略手機震動聲。

### 15｜安全後通報

- A 版：旅客已出站到安全處，目擊的突發事件可能仍在進行。撥 110 時應先準備什麼？
- B 版：已與混亂現場拉開距離，接線員詢問如何定位。哪項資訊優先？

- 甲　先說列車方向與月臺人潮，等對方追問
- 乙　先找齊錄影和完整經過，再說所在站
- 丙　先說站名、目前位置及確定的狀況
- 丁　先留下姓名及可回電的電話

主持人答案為 **丙**。評量原則為「安全後通報」。依據 M1、M4。

- 甲｜抓得到交通線索，但省略站名和目前位置會增加定位時間。
- 乙｜覺得必須有完整證據才可通報，因而拖延。
- 丁｜重視可回電性，容易忽略先定位現場。

### 16｜車廂內通報管道

- A 版：板南線列車行駛中，想將車廂緊急狀況直接告知司機員。哪種方式最適合？
- B 版：在北捷高運量列車上，想直接向司機員報告所在車廂的緊急狀況。怎麼做？

- 甲　在相鄰車廂找人代傳，通知最前方
- 乙　車門旁的緊急對講機，可聯絡司機員
- 丙　向車門旁的攝影機揮手，等司機看見
- 丁　用手機打捷運客服，請轉告值班司機員

主持人答案為 **乙**。評量原則為「車廂內通報管道」。依據 M2、M3。

- 甲｜以為找多位乘客較快，忽略有可直接聯絡司機員的設備。
- 丙｜看到攝影機容易假定有人即時看見並理解意思。
- 丁｜平常客服能回答乘車問題，容易把客服當成直接的車內緊急聯絡。

### 17｜站內通報管道

- A 版：已在站內且避開騷動。怎麼讓本站人員盡快知道現場狀況？
- B 版：在付費區發現突發警訊，想讓本站立即掌握現況。怎麼通報？

- 甲　到閘門旁等穿制服的人主動來問
- 乙　請同行者到站外再告訴路過的保全
- 丙　先用服務表單寫下資訊，由客服轉報
- 丁　聯絡站務或使用站內緊急通報設備

主持人答案為 **丁**。評量原則為「站內通報管道」。依據 M3。

- 甲｜把在可見位置等候當成已完成通報。
- 乙｜平常制服保全好辨認，卻忽略站務掌握本站設備與人流。
- 丙｜熟悉線上客服，容易混淆一般意見回覆和即時通報。

### 18｜依列車人員指示

- A 版：列車在站間停住，附近有人轉述網路留言說應立即自行離開。誰能判斷何時使用逃生設備？
- B 版：故障停車時旅客對何時可使用逃生設備意見不同。哪一道資訊應優先等待？

- 甲　列車司機員或捷運現場人員的指示
- 乙　列車停了一段時間，依旅客共識行動
- 丙　車門設備看起來可操作，就由乘客判斷
- 丁　聽見隔壁車廂喊下車就跟上

主持人答案為 **甲**。評量原則為「依列車人員指示」。依據 M2。

- 乙｜把停車時間和多人同意當作動線已獲確認。
- 丙｜把設備可操作當成外部行車區已經安全。
- 丁｜其他乘客的口頭消息很直接，卻不一定來自有權指揮的人員。

## 低窪住宅淹水

### 19｜積水與觸電

- A 版：室內積水已擋住到配電處的所有路線。要不要涉水去切電？
- B 版：車庫電箱前積水，手套雖然乾燥，靠近仍得走過水。哪個判斷正確？

- 甲　套上家用雨鞋，再走過積水切電
- 乙　用長物件碰開關，人留在積水邊
- 丙　退到乾燥安全處，請專業人員協助
- 丁　手部乾燥就可以走到電箱切電

主持人答案為 **丙**。評量原則為「積水與觸電」。依據 W2。

- 甲｜把防水用品當成符合用電安全的絕緣防護。
- 乙｜誤以為不直接用手就能消除觸電風險。
- 丁｜把乾手這一項條件當成唯一要件，忽略必經積水。

### 20｜垂直避難的條件

- A 版：門外不能安全通過，建物完整且室內樓梯未受阻。哪處可先等救援？
- B 版：無法安全走出住宅，樓上和樓梯目前可用。哪個選址避免進入積水？

- 甲　等看到救援車輛，再往屋外靠近
- 乙　走可通行的室內樓梯去安全高處
- 丙　往大門口靠近，讓外面較快看到人
- 丁　留在一樓較高的桌面等水退去

主持人答案為 **乙**。評量原則為「垂直避難的條件」。依據 W1、W3。

- 甲｜救援人員在附近不代表眼前的水路可自行通過。
- 丙｜接近入口可能好定位，卻忽略題幹已確認走不出去。
- 丁｜室內墊高看似安全，卻忽略水位可能持續上升。

### 21｜避開地下空間

- A 版：坡道已經有水流向地下停車場，有人想先去移車。最重要的顧慮是什麼？
- B 版：地下室入口冒水而照明仍正常。哪項情況最能影響是否下去？

- 甲　以車門底緣估水深，低於它還可下去
- 乙　低處容易快速進水，可能切斷出口
- 丙　地下照明還正常，表示水勢還可控制
- 丁　只要坡道夠寬，車子就能折返

主持人答案為 **乙**。評量原則為「避開地下空間」。依據 W1、W3。

- 甲｜用車的外觀當測量尺，忽略人和出口都可能先受影響。
- 丙｜把仍有電當成抽排水、電氣與逃生動線都正常。
- 丁｜把車輛爬坡能力當成還能走的證據，忽略進水速度。

### 22｜車輛不涉水

- A 版：行車道路前方積水，標線已看不到。哪項判斷最合適？
- B 版：豪雨時地下道口已有積水，看不出深度。駕駛先做什麼較妥當？

- 甲　等前面車少一點，再沿原車道開過
- 乙　慢慢開進一小段，再估水深
- 丙　停在安全處，確認可用替代道路
- 丁　跟在高底盤車後，看它過了就跟上

主持人答案為 **丙**。評量原則為「車輛不涉水」。依據 W3。

- 甲｜人少看似路況改善，但無法確認水深和出入口。
- 乙｜覺得低速可以保留回頭空間，卻忽略車輛可能先失去控制。
- 丁｜他車通過提供直觀參考，但兩車條件與後續水勢不同。

### 23｜通報受困

- A 版：三名住戶已到二樓，樓下積水讓他們出不去。接線時哪組資訊有幫助？
- B 版：居民已到建物較高處等待救援。接線員不知如何尋找，優先提供什麼？

- 甲　提供地址、樓層、受困人數及情形
- 乙　報地標，等回電再補樓層
- 丙　先說室內水位多高，再等對方查位置
- 丁　先說需救助幾人，地址讓鄰居另外報

主持人答案為 **甲**。評量原則為「通報受困」。依據 W4。

- 乙｜手機或地標可協助辨識，但沒有及時說明受困樓層。
- 丙｜重視急迫程度，容易漏掉派遣需要的地點。
- 丁｜誤以為分開通報會自動串聯到同一場救援。

### 24｜退水後用電

- A 版：水已退，浸過水的配電設備從外表看起來乾了。何時比較適合復電？
- B 版：地下空間退水後有人想試開曾受淹的電器。先完成哪一步？

- 甲　先接一件小電器，確認有電再全開
- 乙　開總開關看會不會跳脫
- 丙　等外殼和周圍地面乾了，就先試電
- 丁　由合格電氣人員檢查後再復電

主持人答案為 **丁**。評量原則為「退水後用電」。依據 W2。

- 甲｜用一次試電當成可靠檢測，忽略受淹設備須專業檢查。
- 乙｜把保護裝置沒有動作當成設備沒有問題。
- 丙｜外觀乾燥容易讓人忽略內部仍可能含水或受損。

## 颱風停電

### 25｜照明與明火

- A 版：客廳停電，需要在室內照明一段時間。家中有好幾種照明用品，哪個做法最合適？
- B 版：颱風夜停電，家人需要反覆進出走道旁的房間。怎麼安排照明比較合適？

- 甲　把蠟燭放在穩重容器裡照明
- 乙　有人全程看著才使用蠟燭
- 丙　以電池式頭燈或手電筒照明
- 丁　把油燈放在清空的桌面照明

主持人答案為 **丙**。評量原則為「照明與明火」。依據 T1。

- 甲｜穩重的底座降低傾倒機會，但仍保留明火風險。
- 乙｜有人看著看似可控，仍可能有可燃物或碰撞。
- 丁｜預留空間可減少碰觸，卻不能達到避免屋內明火的目的。

### 26｜安全斷開電器

- A 版：停電後，房內的地面、雙手與電器都保持乾燥。哪些電器安排較適合？
- B 版：颱風停電，插座與用電設備都未受潮。復電前怎麼處理不需要運轉的電器？

- 甲　把非必要電器與插座事先斷開
- 乙　留大功率家電開啟，等復電時確認
- 丙　只把遙控器切到待機，插頭保持接著
- 丁　保留原本的開關設定，復電就用

主持人答案為 **甲**。評量原則為「安全斷開電器」。依據 T1。

- 乙｜想找明顯訊號知道電回來，忽略大功率設備不宜同時啟動。
- 丙｜把待機與切斷連接混同，沒有處理復電的影響。
- 丁｜平時供電穩定時這樣方便，復電時卻可能同時啟動。

### 27｜燃燒廢氣

- A 版：不通風的租屋處把燃油發電機拿進室內後，有人認為沒有味道就安全。最大疑慮是什麼？
- B 版：停電時有人提議把燃燒設備放在室內發電。即使聞不到味道仍可能出現什麼？

- 甲　聞不到廢氣，就能放心在室內用
- 乙　窗邊吹得到風，室內就不會累積廢氣
- 丙　發電機運轉一小段就停，室內便安全
- 丁　無味的一氧化碳可能逐漸在室內累積

主持人答案為 **丁**。評量原則為「燃燒廢氣」。依據 T2。

- 甲｜把嗅覺當成能察覺所有危險廢氣的工具。
- 乙｜把部分空氣流動視為足以排除持續燃燒產生的廢氣。
- 丙｜把運轉時間短直接等同濃度安全，忽略室內環境差異。

### 28｜疑似中毒通報

- A 版：室內正在燃燒，兩人先後頭暈。能安全離開時首先怎麼做？
- B 版：停電時同行者在有燃燒設備的室內出現不適。哪種安排較安全？

- 甲　讓症狀較輕的人留在屋內照看設備
- 乙　先離開至安全處，再聯絡緊急救援
- 丙　先找出廢氣來源並處理，再帶人離開
- 丁　打開門窗留在室內，等頭暈改善

主持人答案為 **乙**。評量原則為「疑似中毒通報」。依據 T3、T5。

- 甲｜把症狀輕當成較安全，忽略繼續暴露的風險。
- 丙｜想先解決原因，容易延長人在危險環境中的停留。
- 丁｜知道通風重要，卻以為只要開窗就可繼續留在疑似危險現場。

### 29｜冷藏安全

- A 版：長時間停電後，冷藏食物已回到室溫，保存時間也不確定。該如何處理？
- B 版：退冰且有變質疑慮的食物，復電後該如何判斷？

- 甲　無法確認保存條件，就避免食用
- 乙　聞起來正常就再次冷藏再食用
- 丙　只要重新徹底加熱，保存不明也能吃
- 丁　外包裝仍完整，就可按原有效期限食用

主持人答案為 **甲**。評量原則為「冷藏安全」。依據 T1。

- 乙｜把氣味當成能判斷所有微生物風險的指標。
- 丙｜平常加熱可減少部分風險，卻不能保證所有不當保存的食物都安全。
- 丁｜把未拆封及標示期限誤當成冷藏條件一直符合。

### 30｜通報管道

- A 版：全棟無電，目前沒有傷者或火警。要直接向供電單位報修，該打哪支電話？
- B 版：颱風過後住家與鄰居都停電，現場平安。要直接向供電單位查詢，該打哪支電話？

- 甲　打警察 110 請查詢復電時間
- 乙　撥市民 1999，等市府安排復電
- 丙　撥台電 1911，查詢或通報停電
- 丁　撥消防 119，請協助報修停電

主持人答案為 **丙**。評量原則為「通報管道」。依據 T3、T4。

- 甲｜有人習慣在突發事件打警察電話，卻不是查詢台電復電的直接管道。
- 乙｜知道市府能協助民生問題，卻把受理轉介當成直接報修。
- 丁｜遇到颱風會想到消防資源，容易混淆一般停電與火災救護。
