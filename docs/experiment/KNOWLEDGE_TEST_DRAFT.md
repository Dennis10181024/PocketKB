# PocketKB 防災前後測題庫

**草稿，待人工審查。** 本檔含答題原則與答案，供教授及施測主持人使用。正式施測時，只發當次版本的題幹與選項。

五個劇本每個六題，共 30 個知識題目。每題有等原則的 A／B 情境題幹，搭配三個共同選項。預計用 A→B 與 B→A 平衡前後測；延遲測須先定案第三套題幹或重測方案。試測每題兩版答對率與語意，不能假定兩版難度已等化。主持人也可在保留題號與答案對照下調整選項位置。

正式施測以納入的劇本範圍計分，正確 1、其他作答 0、未作答與退出各自標記。捷運題內容涉及突發攻擊，讀題前提示並允許跳過。前後測題幹換用新場景或問原理，避免重複 App 選項文字。

## 宿舍火災

### 01｜煙熱判斷

- A 版：旅館房門另一側有濃煙，門也發熱。能否以走道短就判定可走？
- B 版：在補習班的房內得知必經通道已有濃煙，高溫也逼近。哪項資訊比到出口的距離更重要？

- 甲　煙熱使通道不宜通過
- 乙　步行距離能保證安全
- 丙　看得到出口燈就能通過

主持人答案為 **甲**。評量原則為「煙熱判斷」。依據 F1、F2。

### 02｜隔煙目的

- A 版：公共走道煙很重，房內尚未充滿煙。保持門關閉主要在爭取什麼？
- B 版：樓梯動線已失去通行條件，同行者問為何要保留一扇完整關閉的門。對室內最直接的效果為何？

- 甲　提高手機收訊強度
- 乙　讓樓層的火警聲停止
- 丙　減慢煙進到室內

主持人答案為 **丙**。評量原則為「隔煙目的」。依據 F1。

### 03｜受困空間

- A 版：目前無法循安全路線離開，有窗的房間仍可對外聯繫。即使浴室有水，哪個考量更重要？
- B 版：走道已完全無法通過，可選擇能向外求助的空間或只有自來水的無窗空間。哪項條件更有助於求救？

- 甲　把所有室內燈全部熄掉
- 乙　能讓外界知道受困位置
- 丙　水龍頭可以一直放水

主持人答案為 **乙**。評量原則為「受困空間」。依據 F1。

### 04｜避免搭乘電梯

- A 版：辦公樓收到火警通知，電梯的樓層顯示仍正常。這能證明它可供逃生嗎？
- B 版：商場疏散時有人指出電梯內燈仍亮。哪個判斷較妥當？

- 甲　火警時不能單憑設備有電就使用
- 乙　電梯門仍能開表示路線安全
- 丙　平常較快的電梯也適合火警時使用

主持人答案為 **甲**。評量原則為「避免搭乘電梯」。依據 F2。

### 05｜濕布的限制

- A 版：有人表示只要隔著濕布呼吸，就能穿過火場濃煙。這個說法忽略什麼？
- B 版：房內沒有現成毛巾。有人想穿過煙區去找，因為相信沾水後能阻擋有害氣體。哪個判斷較妥當？

- 甲　布料含水時便等同濾毒設備
- 乙　先找到較厚的布便可走煙區
- 丙　濕布無法把有毒氣體濾掉

主持人答案為 **丙**。評量原則為「濕布的限制」。依據 F1、F4。

### 06｜具體通報

- A 版：民宿內有三人無法離開，接線員還不知道地點。哪一組資訊較有助於定位？
- B 版：租屋處有一人受困，門外已有煙。通話剛接通時哪種說法較有助於救援？

- 甲　先描述今天到訪這裡的經過
- 乙　提供地址、樓層位置與受困情形
- 丙　只說附近店家與自己的姓名

主持人答案為 **乙**。評量原則為「具體通報」。依據 F3。

### 11｜戶外落物

- A 版：地震後來到有外牆、路燈和空地的校園廣場。哪處更適合短暫集合？
- B 版：樓內人員離開後在校園找集合點。選點最好考量什麼？

主持人答案為 **乙**。評量原則為「燃燒廢氣」。依據 T2。

### 28｜疑似中毒通報

- B 版：停電時同行者在有燃燒設備的室內出現不適。哪種安排較安全？

- 甲　離開至安全處，聯絡緊急救援
- 乙　在房間內觀察症狀再說
- 丙　請有症狀的人回去查看設備

主持人答案為 **甲**。評量原則為「疑似中毒通報」。依據 T3、T5。

### 29｜冷藏安全

- A 版：長時間停電後，冷藏食物已回到室溫，保存時間也不確定。該如何處理？
- B 版：退冰且有變質疑慮的食物，復電後該如何判斷？

- 甲　放回冰箱冷卻便會恢復安全
- 乙　先少量試吃便能判斷風險
- 丙　保存安全無法確認就避免食用

主持人答案為 **丙**。評量原則為「冷藏安全」。依據 T1。
