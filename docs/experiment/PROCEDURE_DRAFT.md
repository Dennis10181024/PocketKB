# PocketKB 防災學習研究流程

草稿，待人工審查。介入目標為一次三個固定情境包加回顧，約 30–45 分鐘；實際時長以組員與小規模真人前導量測確認。下列時間均為安排草案。

正式實驗採 **方案 B：宿舍火災、學校地震、低窪淹水**。劇本範圍已確定，正式收案前仍需完成人工內容與研究審查，並鎖定三包的版本及摘要。

| 階段 | 做法 | 留存資料 |
| --- | --- | --- |
| 招募與同意 | 預計招募成年一般大眾及大學生。說明三個災害模擬及受傷、受困內容，提供跳過及與成績脫鉤的退出方式。 | 同意、招募與聯絡資料分開保管；分析資料用研究代碼。 |
| 前測（約 8–12 分鐘） | 使用此次三個劇本對應的知識題，題序與答案位置按事先排程，施測者不解題。視核准內容收集自陳防災經驗及裝置別。 | 題版、題號、答覆、未答原因、耗時與裝置別。 |
| 演練（約 24–34 分鐘） | 使用審查通過並鎖定 digest 的三包；Android 或 HTTPS PWA 以固定旁白離線。關閉生成變體、自由輸入、模型問答及相機。共同主持流程先給 1 分鐘示範。 | 選項順序、首次安全選擇、致命事件、重來、等級與退出。 |
| 回顧（約 6–11 分鐘） | 完成或提前終局時閱讀結果、關鍵轉折、官方依據，可按安排重來。回顧固定時長上限，演練與回顧合計以 30–45 分鐘為目標。 | 回顧完成與否、重來次數、是否完成場次。 |
| 立即後測（約 8–12 分鐘） | 改用同原則的新情境題，不給解答。在各研究組採相同設備和監考方式。 | 題版、答案、未答與耗時；另收可選填的使用感受。 |
| 延遲測（建議 7 天，前後容許 2 天） | 使用輪替題版；在延遲測前記錄是否另接觸防災教材或試玩其他版。延遲測後提供核准答案與教材。 | 實際相隔天數、測驗分數、失訪、額外接觸自陳。 |

## 方案紀錄與自主練習

- **方案 A（原計畫）**為宿舍火災、學校地震與捷運攻擊。保留為方案選擇紀錄，正式介入與正式題本均不包含捷運。
- 延遲測及正式參與流程結束後，若專業與倫理審查允許，可另提供捷運劇本讓參與者自主試玩。開啟前提供獨立內容提醒，可跳過。自主練習資料不併入正式介入分析。

## 比較與分析

建議以內容與接觸時間相近的官方短教材加案例題作對照。對照組同樣有前測、等量學習與回顧、立即後測、延遲測。組別採集中的隨機分派，並在分析前決定分層、樣本數與排除條件。若目前只能做單組前後測，定位為前導可行性與短期變化，因果效果不作推定。[情境演練教育研究整理](../../SCENARIO_TRAINING_EDUCATION_RESEARCH.md)

主要指標草案為知識題分數的前後差，延遲測看保留。首答安全率、致命錯誤、重來完成、各題反應時間為過程指標。測驗未答、跳過指定劇本、退出和延遲測未到分開編碼；分析時呈現各組樣本與分母，不將空白一概視為答錯，計分方法事前定案。[研究指標計算](../METRICS_GUIDE.md)

## 教授需定案

1. 校方審查流程、研究主持人、招募對象與排除條件、資料保存期限與閱覽權限。
2. 確認方案 B 三個情境包的審查簽核與研究定版摘要，特別複核低窪淹水的用電限制、可達高處及前導測驗結果。
3. 樣本數、對照條件、分派方法、唯一主要結果與延遲測時間。若同場使用兩種裝置，預先決定分層或固定裝置。
4. 題版分配、未答與退出處理、替代題本難度與語意查核。題庫先做專業審查，再做題意與內容理解前導。
5. 關鍵介入步驟、回顧是否允許重來、分配多少次重來，以及主持人能說到什麼程度。正式場次鎖定 app 版本、包 digest、題本版本與模型設定。
