# PocketKB 防災學習研究參與同意書

草稿，待人工審查。待主持人、指導教授與校方審查程序確認，填妥方括號後才能供招募使用。

**研究名稱**［核准計畫名稱］　**研究單位**［系所與學校］
**研究主持人與聯絡方式**［姓名、電話與電子郵件］　**參與權益聯絡窗口**［校方單位與方式］

## 邀請內容

本研究想了解文字選擇題情境能不能幫助大眾理解、記住並運用防災原則。若您同意，會先做防災知識題，再依分派方式使用 App 或閱讀等量防災教材，最後完成回顧、立即後測與一次延遲測。建議介入時間 30–45 分鐘，測驗另計；確切時間、間隔與交通或費用補助由主持人於招募前告知。參與可能幫助您練習，實際學習成效因人而異。

## 可能的不舒服

正式活動包含宿舍火災、學校地震和低窪淹水的文字情境。畫面可能出現受困或非血腥的受傷結果，也可能使您感到緊張。您可以跳過、暫停或停止任何題目，無須說明理由。研究人員不會要求您描述私人經歷。選擇退出或跳過不影響成績、課程、權益或與學校的關係。

### 研究結束後的自主練習（選填）

若校方審查同意，完成延遲測與正式活動後可自行選擇試玩捷運情境。此情境包含突發攻擊、人群恐慌和非血腥的受傷描述，開啟前會另外提醒。可以略過或隨時停止，無須提供試玩紀錄。若另有研究用途，團隊會另外說明收集內容並徵求同意。

## 要保存的資料

研究採編碼保存。開始前會給您研究代碼，用於配對前測、後測、延遲測與退回資料。試玩檔會含場次代碼、情境包版本與摘要、嘗試編號、選項代碼、顯示順序、作答時間、選擇後果、結局、傷勢等級及退出狀態。測驗保留每題答案；任何必要的聯絡方式與簽署資料分開保存。

- 正式版使用固定情境包，預設關閉自由輸入，不保存自由輸入文字、模型輸出全文、照片原圖、GPS 或 IP。正式場次不使用拍照或圖片生成。
- 自願參加另行設計的功能測試時，需另取得同意。現行規格如需線上產生圖片，第一版只傳送刪減後的場景描述；照片原圖不得上傳。正式場次資料不會併入這類測試。
- 草稿建議僅主持人與核准研究成員存取編碼資料，對照表獨立限權保存。資料置於［校方核准的加密空間］並留存存取紀錄。公開成果以彙整統計或無法辨識個人之資料呈現。CSV、原始 JSONL 與連結表不上傳 GitHub 或一般公開分享空間。
- 建議個別資料保存至研究結案後 12 個月［待教授及審查單位定案］。期限到期按核准辦法刪除或銷毀對照表與個別資料，備份同樣納入。必要留存例外及適用情況須在招募前說明。

## 自願參加與撤回

若要停止，告知現場研究人員即可。若要撤回同意或要求刪除仍可對應的資料，可於［停止接受刪除請求的日期或事件］前，以研究代碼聯絡［方式］。去連結或納入已發布的彙整後，研究人員可能無從辨識是哪一筆；具體時點會在招募前告知。您也可以詢問資料處理方式或提出更正、停用、刪除等請求，由研究單位依校方規範與適用規定處理。
