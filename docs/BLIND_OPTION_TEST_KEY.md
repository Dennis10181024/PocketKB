# PocketKB 選擇題盲測答案與計分

草稿，待人工審查。此檔由主持人保留，收卷後再公開。

正確答計 1 分，其他有效選項計 0 分，空白、多選或跳過個別記錄。單題答對率＝答對人數 ÷ 該題有效作答人數。答對率嚴格大於 80% 的題目標記「可能太好猜」，剛好 80% 不標記。請同時列出有效樣本數，少量答卷僅提供修題線索。

題本離開了互動時序；主持人可讓作答者圈出「靠文字外形猜到」的題，另記以前是否玩過正式題組。答對率用於修整選項，不代表訓練成效。
