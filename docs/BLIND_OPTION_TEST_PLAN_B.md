各題以當下資訊選一項最適合的做法，在答案欄填 A、B、C 或 D。可跳過任何題目。看完題本前請先不要試玩或查看答案。

## 宿舍火災

### 1-1　門外有人喊「503 有人嗎？」我怎麼回應？

- A　我拿起房卡和手機，收好物品再回應。
- B　我大聲回報房號人數，留在門內等候指示。
- C　我貼近門邊聽清楚，再示意小岑安靜等候。

答案：＿＿

### 1-2　走廊已經看不清，小岑想把房門拉開。我先做什麼？

- A　我關緊房門，拿起手機準備通報。
- B　我關緊房門，提醒小岑留在房裡。
- C　我拉開房門看看，想找煙比較淡的路。
- D　我看電梯燈還亮著，出門去搭電梯下樓。

答案：＿＿

### 1-3　小岑還站在門附近，擔心其他人沒收到警報。我怎麼回應？

- A　我提醒小岑別開門，拿起房卡做準備。
- B　我叫小岑留在門邊，自己進浴室避煙。
- C　我請小岑開門一點，再對隔壁喊一聲。
- D　我請小岑留在房裡，陪我核對房號。

答案：＿＿

### 1-4　手機在手上，外面還不知道我們在哪一間。我怎麼通報？

- A　我走到窗邊揮衣，再喊樓下幫忙報案。
- B　我打119，說宿舍的地址和受困人數。
- C　我打119，報地址、房號、人數和煙況。
- D　我翻出房卡和證件，整理好再拿手機。

答案：＿＿

### 1-5　我聞到靠門的地方有一股焦味，桌邊和窗旁都看得見。我先怎麼處理？

- A　我把房門開一點，探頭找煙是從哪來的。
- B　我把房門拉緊，退到窗邊留意外面。
- C　我把門帶緊，用手邊的布塞住門縫。
- D　我握住門把試著拉緊，再摸門底找漏縫。

答案：＿＿

### 1-6　外面的人可能看不到房裡的我們。我怎麼讓對方找到房間？

- A　我往窗下的平台跳，避開走廊的煙。
- B　我看清窗外煙況，在窗內揮衣呼救。
- C　我踩上窗外的架子，再向樓下揮手大喊。
- D　我靠窗看看煙飄向哪，找樓下人影。

答案：＿＿

### 1-7　手機電量不多，外面仍在確認位置。我怎麼安排通訊？

- A　我帶手機進浴室關門，找訊號再打電話。
- B　我打119補報房號，保持這支電話暢通。
- C　我留在房內，關掉耗電的程式省電。
- D　我把手機調暗、關程式，再把手機收起來。

答案：＿＿

### 1-8　走廊視線仍被濃煙遮住，門外還沒敲門。我接下來怎麼做？

- A　我趁外面安靜開門，沿牆去找樓梯。
- B　我進浴室把門關上，靠牆等走廊的煙退。
- C　我關緊房門，在房裡留意救援喊聲。
- D　我待在房內窗旁，仔細聽門外動靜。

## 學校地震

### 2-1　教室突然劇烈搖晃，桌椅開始移動。我第一步做什麼？

- A　我縮進桌下，雙手抱住頭頸擋落物。
- B　我扶著桌沿站起來，趁門開著跑到走廊。
- C　我趴到桌下護頭頸，牢牢抓穩桌腳。
- D　我蹲進櫃子旁的空隙，扶著櫃子穩住。

答案：＿＿

### 2-2　小維說：「我想拉開後門，叫隔壁班一起走。」我怎麼回他？

- A　我示意小維回桌下，自己也留在桌邊。
- B　我叫小維先走到門邊，扶住門框等開門。
- C　我請小維留在桌下，陪他等搖晃停止。
- D　我招手叫小維跟來，跑到門邊看隔壁班。

答案：＿＿

### 2-3　剛要起身，教室又晃了起來，桌腳在地上滑。我怎麼應對？

- A　我趴回桌下護頭頸，抓牢桌腳等震動過去。
- B　我移到櫃旁蹲低，扶櫃等搖晃變小。
- C　我翻過窗台，想沿低處平台避開落物。
- D　我扶著桌沿起身，趁空檔跑出教室。

答案：＿＿

### 2-4　老師說可以疏散。樓梯前已排了幾個班，另一側有電梯。我怎麼離開？

- A　我貼著扶手快步下樓，趕在後隊之前。
- B　我護好頭頸，留出距離跟隊走樓梯。
- C　我跟著班級走樓梯，和前面留好距離。
- D　我改走電梯，按一樓去外面找隊伍。

答案：＿＿

### 2-5　出口外牆掉了幾塊碎片，前方還垂著一條線。我選哪條路？

- A　我繞開外牆和電線，往操場空地走。
- B　我走上前抓住電線，挪開替同學開路。
- C　我貼著外牆走，順著牆繞開正前方的線。

答案：＿＿

### 2-6　操場上幾個班正在集合，熟識的同學朝我招手。我在哪裡等？

- A　我找到本班老師，回到原班位置等候。
- B　我先到朋友班上，站到隊尾等老師點名。
- C　我先回教室找手機，拿到後趕回操場。

答案：＿＿

### 2-7　老師正喊我的名字，小維還沒被確認。我回應什麼？

- A　我應聲確認到場，回報小維的位置和傷勢。
- B　我跟同學核對名單，等老師再叫一次。
- C　我離開隊伍找小維，想和他一起回報。

答案：＿＿

## 低窪住宅淹水

### 3-1　雨聲蓋過排水口的聲音，屋內地板、手和總開關一帶仍乾燥。我先處理什麼？

- A　我確認乾燥，再切斷屋內總電源。
- B　我搬高延長線，再整理插頭。
- C　我開著電器先收拾物品，等雨停下。

答案：＿＿

### 3-2　門縫冒進一線混水，電箱前方已有積水；乾側的梯口仍看得見。我怎麼選？

- A　我踩水走到電箱，想確認開關位置。
- B　我在玄關鋪毛巾，再拿拖把吸水。
- C　我避開電箱，往乾側梯口退。

答案：＿＿

### 3-3　坡道底湧出水聲。阿哲攥著車鑰匙，說再晚就來不及移車。我怎麼回他？

- A　我陪阿哲退到梯口，請他留在乾處。
- B　我站在乾處，先讓阿哲下去看。
- C　我跟他走下車庫，想趁水淺把車移走。

答案：＿＿

### 3-4　巷口一輛車停下，水流遮住路面標線。鄰居喊說外面也許還能開出去。我怎麼判斷？

- A　我去開車，沿別人的車道穿過積水。
- B　我留在乾側，再找可走的樓梯。
- C　我留在門邊，等別的車先試。

答案：＿＿

### 3-5　原本的出入口已被水截斷；這棟樓外觀無可見損壞，室內兩段高度可到。我怎麼選停留位置？

- A　我停在半層等水退，再考慮往上。
- B　我從乾燥的樓梯直接走上二樓。
- C　我回頭繞向門口，再找地方墊高等候。

答案：＿＿

### 3-6　我到二樓了，巷口的水隔斷外出動線。手機還有訊號，現在怎麼聯絡外面？

- A　我拍下水位，傳房東後再通話。
- B　我拍下上漲的積水，貼社群請人轉報。
- C　我打119，報地址和兩人受困位置。

答案：＿＿

### 3-7　我聽見外面有人喊話，樓下仍有水聲；窗邊和樓梯口都看得到。我怎麼回應？

- A　我往樓下走，看誰在喊我。
- B　我在二樓安全的窗內向外示意。
- C　我往地面入口移動，想在門口接應。

答案：＿＿

### 3-8　救援人員已接手。水退時留下的水線還在插座旁；有人提議試電，我怎麼處理？

- A　我保持設備原狀，等合格電工檢查。
- B　我插回延長線，想測樓下的電力。
- C　我確認插座外面乾了，請房東先復電。
