# PocketKB 研究資料統計工具

草稿，待人工審查。此工具用合成資料驗證，沒有產出受試者研究結果。

## 執行

```powershell
node scripts/metrics/index.js --out output/metrics-run session-web.jsonl session-android.jsonl
```

Web 在試玩頁下載 `PocketKB-*.jsonl`；Android 在選擇題紀錄匯出 Room JSONL。可一次傳入多個檔案或不同版本，同一場避免改動原始列。檔案請存放在研究團隊核准的本機位置。建議每批使用新的輸出目錄，命令會覆寫同名的三個統計檔。CSV 使用 UTF-8 BOM 供 Excel 開啟。HTML 不含原話、敘事、完整場次 ID 或外部資源。

| 輸出 | 內容 |
| --- | --- |
| `attempts.csv` | 場次及包版本、每次嘗試、終局、傷勢、首答分子與分母、致命計數、已知未答與作答時間加總 |
| `responses.csv` | 每個有效答題的選項 ID、顯示順序、位置、回應時間、可取得的背景和觀察時間 |
| `summary.html` | 整批的主要指標、重來結局分布和各題平均作答時間；作答時間按情境、版本及初次／重來分列 |

## 定義與分母

| 指標 | 計算與限制 |
| --- | --- |
| 首次決策安全率 | 只看初次嘗試。同一場同一決策只計最早的有效結算選項；分子為 `safety=safe`，分母為有效首答。退出前有效首答仍計入；沒答、只觀察、未採用的動作與重來的作答不放進分母。 |
| 致命錯誤次數 | 結算列的 `fatal=true`，先以情境、情境包、場次、嘗試、決策 ID、出現次序去除重複。每次重來為獨立嘗試，另保留場次累計。危急停止的名稱不單獨當作致命錯誤。 |
| 重來後完成率 | 分母為有重來標記或留下作答／退出的 `attempt>1`；分子為自行撤離、延誤撤離、安全獲救或延誤獲救。危急失敗、主動退出、未看到終點各自列出。若只有重來標記也計入分母。 |
| 作答時間 | 使用紀錄內的 `responseTimeMs` 毫秒數，涵蓋選項可操作到送出；零毫秒是有效值，空白不估算。按程式平台的背景暫停規則取得。觀察時間若有另外提供，照實輸出，避免再從已扣除背景的主值重複扣除。 |
| 已知未答 | 有明確開始、重來或退出資料指向該題，且該次嘗試沒有有效選擇。關頁前未匯出、舊 Android 紀錄未列未呈現的決策，工具無法推算。 |

整批比率採先加總分子與分母。沒有有效分母的項目顯示「無適用資料」。依摘要優先區分版本；只有版本號的舊資料在能唯一對應同場次摘要時合併，其他情況保留分開。若兩份紀錄的同一回合在選項、終局、已記錄排序或時間有衝突，程式報錯供人工核對。非選擇題舊對話或無效列會列入略過計數；破損 JSONL 需先修復或排除原檔。在研究解讀時，分開正式固定情境包、草稿、組員試玩與合成資料。

合成測試 `node --test online-coach/test/metrics.test.js` 包含中途退出、未答、重來多次、排序差異、同題重複出現、重複匯入、分母為零與格式錯誤。
